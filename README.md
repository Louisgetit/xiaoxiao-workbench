# 🌿 小小工作台

清新、可爱、轻量的个人工作台 —— 一个页面管理你的日常生活。

纯前端单页应用，**零依赖、零后端**，数据全部保存在浏览器本地，支持安装到手机桌面离线使用。

## ✨ 功能模块

| 模块 | 功能说明 |
|---|---|
| 🏠 **首页** | 每日随机鼓励语、农历日期、三伏天提示；卡片式仪表盘一览今日待办 / 学习 / 运动 / 记账 / 喂养 / 提醒 |
| 📝 **待办** | 今日 / 近期 / 逾期分区管理；支持日期、时间、优先级、备注；底部年月日历，点击查看当天事项 |
| 📓 **学习** | 每日 30 个高频词汇 + 5 句高频语句；音标、例句、朗读、独立勾选打卡；每日 0 点自动更新；完成率热力图可回溯 |
| 🏋️ **减脂** | 运动记录（自定义项目 / 时长 / 备注）+ 饮食记录（三餐 / 加餐 / 饮品）；日历标注三伏天；800ml 芡实赤豆薏米茶每日打卡 |
| ⭐️ **星仔** | 默认 6 项喂养清单（可自定义），支持勾选、备注、手动新增；喂养日历查看历史 |
| 💰 **记账** | 日 / 月 / 年累计收入、支出、结余；分类统计、每日柱状图、备注搜索 |
| 📰 **新闻** | 全部 / 国内 / 国外 / 经贸 四个分类，各 10 条精选；每日 10:00 自动更新 |
| 📅 **纪念** | 纪念日与生日管理；**支持公历 + 农历（含闰月）双历联动换算**；倒计时排序 |
| 🌸 **经期** | 经期记录与统计；日历标注经期、预测经期、排卵日、易孕期 |
| ⚙️ **设置** | 个人资料、偏好配置、星仔清单管理、数据导出 / 导入 / 清空 |

## 🎨 设计

- **视觉风格**：浅墨绿渐变背景 + 玻璃拟态半透明卡片 + 柔和阴影
- **布局**：左侧固定导航（正方形图标 + 文字标签），首页为总览中心
- **主题色**：薄荷绿 `#8fd4b4` / 墨绿 `#4fb08d`

## 🚀 部署到 GitHub Pages

### 方法一：网页上传（推荐新手）

1. 登录 GitHub，点右上角 **+** → **New repository**
2. 仓库名填 `xiaoxiao-workbench`，选择 **Public**，点 **Create repository**
3. 在仓库页面点 **uploading an existing file**
4. 把本文件夹里 **所有文件和 `icons` 文件夹** 拖进去，点 **Commit changes**
5. 进入 **Settings** → 左侧 **Pages**
6. Source 选择 **Deploy from a branch**，Branch 选 **main** + **/ (root)**，点 **Save**
7. 等待 1–2 分钟，页面顶部会出现你的网址：
   ```
   https://<你的用户名>.github.io/xiaoxiao-workbench/
   ```

### 方法二：命令行

```bash
git init
git add .
git commit -m "init: 小小工作台"
git branch -M main
git remote add origin https://github.com/<你的用户名>/xiaoxiao-workbench.git
git push -u origin main
```

然后同样到 **Settings → Pages** 开启即可。

## 📱 添加到手机桌面

部署完成后，用手机浏览器打开你的 GitHub Pages 网址：

**iPhone（必须用 Safari）**
1. 点底部「分享」按钮 ⬆️
2. 选择「添加到主屏幕」→「添加」

**Android（Chrome / Edge）**
1. 点右上角菜单 ⋮
2. 选择「安装应用」或「添加到主屏幕」

完成后桌面会出现绿色嫩芽图标，点开即全屏运行，**支持离线使用**。

## 💾 数据说明

- 所有数据保存在浏览器 `localStorage`，**不上传任何服务器**
- 数据与「域名」绑定：换域名、清除浏览器数据、卸载重装都会丢失
- **强烈建议**定期在 **设置 → 数据管理 → 导出备份** 保存 JSON 文件
- 换设备时用「导入备份」恢复

## 🔧 技术说明

- 原生 HTML / CSS / JavaScript，无构建步骤，无框架依赖
- 农历换算基于 [solarlunar](https://www.npmjs.com/package/solarlunar)
- 三伏天按「夏至后第三个庚日入伏、立秋后第一个庚日末伏」算法推算
- 单词朗读使用浏览器内置 Web Speech API
- PWA 支持安装到桌面与离线访问
